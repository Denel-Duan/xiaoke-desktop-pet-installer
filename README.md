# Clawd Mochi Codex 一键安装包

Clawd Mochi CX 有线 USB 版的 Codex 配置包，同时支持 Windows 和 macOS。

## 下载

- [Windows 一键安装包](packages/Clawd-Mochi-Codex-Windows.zip)
- [macOS 一键安装包](packages/Clawd-Mochi-Codex-macOS.zip)

## Windows

1. 解压全部文件。
2. 用数据线连接 Mochi。
3. 双击 `INSTALL.cmd`。
4. 重启 Codex，输入 `/hooks` 确认 Hook 已启用。

## macOS

1. 解压全部文件。
2. 用数据线连接 Mochi。
3. 双击 `INSTALL.command`。
4. 按安装器提示进入 Codex CLI，输入 `/hooks` 完成首次信任。
5. 完全退出并重新打开 Codex 桌面端。

如果 macOS 阻止运行，右键 `INSTALL.command` 并选择“打开”。
